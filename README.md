# Влияние контентных эмбеддингов на рекомендации

Проект посвящён оценке влияния контентных эмбеддингов на качество рекомендательных моделей на открытом датасете [VK-LSVD](https://huggingface.co/datasets/deepvk/VK-LSVD).

## Задача

- реализовать коллаборативные алгоритмы Popularity, ALS и BPR;
- построить контентную и гибридные рекомендательные модели;
- сравнить модели по Recall@10, NDCG@10, MAP@10, HitRate@10 и Coverage@10;
- проверить устойчивость результатов и качество в пользовательских и товарных сегментах.

## Экспериментальный протокол

Использовано временное разделение данных:

- недели 00–24 — обучение;
- неделя 25 — валидация и выбор конфигурации;
- неделя 26 — финальное тестирование.

Такое разделение исключает использование будущих взаимодействий при обучении модели.

## Основной результат

Лучшим общим решением на тестовой неделе оказался BPR:

- NDCG@10: `0.00797`;
- Recall@10: `0.00849`;
- HitRate@10: `0.05535`.

Добавление мультимодального контентного эмбеддинга улучшило качество на валидации, но преимущество не сохранилось на следующей тестовой неделе. Это показывает необходимость проверки гибридных конфигураций на последовательных временных периодах.

## Структура

- `VK_LSVD_Project.ipynb` — полный воспроизводимый эксперимент;
- `outputs/` — итоговые таблицы и визуализации;
- `requirements.txt` — основные зависимости.

Исходные данные не включены в репозиторий. Notebook загружает необходимые файлы VK-LSVD отдельно.

## Запуск

```bash
pip install -r requirements.txt
jupyter notebook VK_LSVD_Project.ipynb
```
